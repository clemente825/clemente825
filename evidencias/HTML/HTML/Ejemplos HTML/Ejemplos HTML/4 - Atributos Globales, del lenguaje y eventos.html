Atributos Globales en HTML

Los atributos globales pueden aplicarse a cualquier elemento HTML.

id (Identificador único)

Este párrafo tiene un ID único. No puede haber otro elemento con el mismo ID en esta página.

class (Clases reutilizables)

Este párrafo combina dos clases: "destacado" e "importante".

style (Estilo en línea)

title (Tooltip informativo)
