Guía de Referencia de Protocolos de Red

Conceptos principales

HTTP
Protocolo utilizado para la comunicación entre navegadores y servidores web.
FTP
Protocolo utilizado para transferir archivos entre equipos.
DNS
Sistema que relaciona nombres de dominio con direcciones IP.

Bloque de código

GET /inicio.html HTTP/1.1
Host: servidor.ejemplo
Accept: text/html
