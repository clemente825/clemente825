# Quina diferència hi ha entre una llista i un diccionari?
Una llista es una serie de noms o elements ens serveix de ajude per fer el inventari després, un diccionari es com la definició d'aquell nom o element. Com un diccionari tradicional, però adapatat a python.
# Per què utilitzem una llista de diccionaris?
Per poder almacenar una colecció de objectes on cada objecte té multiples propietats.

# Com funciona el guardat a fitxer?
Doncs en una opció del programa tenim una opció que ens permet saber que tenim guardat al .txt aixó funciona amb un script. Tot el que el usuari li escriu al programa ho llegeix, ho escriu al arxiu txt i ho tanca. Quan obrim aquest fitxet doncs están tots els numeros i coses que li hem indicat.
Tot a base de permisos de escritura, llegir i agregar i després tancarlo com un arxiu de normal.
